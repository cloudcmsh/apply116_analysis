# 四技申請入學參採科目比較

這個資料夾就是完整的靜態網站，不需要安裝套件或執行建置指令。`index.html` 為首頁；`data/` 已包含 115、116 年的來源 PDF、115 年最低篩選標準 PDF、115 年簡章及校系分則詳細 PDF，以及整理後的資料。權重原始工作簿不隨網站提供。

## 上傳 GitHub Pages

1. 在 GitHub 建立儲存庫，將 **本 `web` 資料夾裡的所有檔案與子資料夾** 上傳至儲存庫根目錄。請保留 `data/115/`、`data/116/` 的目錄結構。
2. 到儲存庫的 **Settings → Pages**，將來源設為 **Deploy from a branch**，選擇 `main` 分支及 `/ (root)`，然後儲存。
3. 等待 GitHub Pages 顯示網址，即可開啟網站。

若把 `web` 當作儲存庫內的一個子目錄上傳，GitHub Pages 的一般分支設定無法直接指定 `web` 作為網站根目錄；最簡單的方式是上傳 `web` **裡面的內容** 到儲存庫根目錄。

## 本機檢視

在這個資料夾執行 `python -m http.server 8000`，再開啟 `http://localhost:8000/`。首頁資料由本機 `data/programs.js` 載入；「115 簡章計分規則」與「115 校系詳細簡章」使用 `data/` 內的 PDF。站內檢視器使用隨網站提供的 PDF.js（授權條款見 `vendor/LICENSE.pdfjs.txt`），可在手機顯示指定頁碼。

## 資料範圍

- 116 學年度：592 筆校系、58 所學校。
- 115 學年度：588 筆參採科目紀錄；最低篩選標準原表有 593 筆。
- 115 年權重工作簿有 593 筆唯一志願代碼，與最低篩選標準原表逐碼對應。最低標準視窗可查六科權重與加權平均計算式。
- 115 年詳細簡章的 593 筆校系均已依志願代碼擷取第二階段複試評分項目及甄試全部評分項目比率，完整資料另存於 `data/second_stage_115.json`；每筆有數值的比率合計為 100%。116 年資料預留待正式簡章公布後補入。
- 年度參採科目比較以學校代碼與校系名稱配對；長庚科大「嘉義分部／嘉義校區」依 115 年詳細簡章確認為同一校系（237002、237006）。有 551 筆 116 校系可查 115 年最低標準與權重；參採科目未配對的 41 筆可能包含更名、改組或同名重複，須回查原始 PDF。
- 權重視窗的 116 欄位預留待 116 年簡章公布後補入；目前「待公布」不表示不採計。

資料由同層專案根目錄的 `build_data.py` 從來源 PDF 產生。若日後重新整理資料，請在專案根目錄執行 `python build_data.py`。
